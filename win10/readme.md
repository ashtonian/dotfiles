# Windows archive

The [init.ps1](init.ps1) package list is a historical Windows 10 reference. It is
not maintained or tested by the macOS installer or regression suite. Package
identifiers and availability have not been refreshed for a current Windows
installation.

Do not treat it as an unattended bootstrap: review each package and the current
package manager instructions before installing anything. It includes obsolete
software names. Earlier versions of this README also included system debloat and
security-setting changes; those commands are retained only in Git history and
are not part of the supported dotfiles setup.

Use the [main README](../README.md) for the maintained macOS workflow.
